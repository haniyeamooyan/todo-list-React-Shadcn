# Todo List with shadcn/ui

A task manager built with React and TypeScript, using shadcn/ui and Radix UI primitives for a clean, accessible interface.

## Features

- Create, edit, complete, and delete tasks
- Filter tasks by status
- Mark all tasks as complete
- Manage shared state with the Context API
- Use dialog, select, checkbox, and toast interactions

## Tech stack

- React 18
- TypeScript
- shadcn/ui
- Radix UI
- Tailwind CSS
- Context API
- Vite

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
